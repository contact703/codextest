# adtool

Ferramenta de linha de comando para automatizar a geração de audiodescrição brasileira conforme as diretrizes do projeto Audiodescrição Toolkit.

## Instalação

```bash
pip install -e .[dev]
```

## Uso rápido

```bash
adtool pipeline --input caminho_ou_url --out ./outputs
```

Consulte `adtool --help` para detalhes de cada comando.
